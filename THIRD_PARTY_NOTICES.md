Stunts / 4D Sports Driving is the name of the original game. The optional Game view includes original graphical resources described below. No original DOS executables or sound files are distributed. The map uses independently authored simplified vector diagrams; tile names and identifiers describe file-format compatibility.

The five original editor terrain layouts (900 terrain identifiers each) are taken from `public/game/editor-terrain-presets.json` in the workspace's PlayStunts source. Only their terrain grids are included, excluding the resource footer and any track tiles. The 19 terrain types follow PlayStunts terrain identifiers. Terrain symbols are independently drawn SVG diagrams using the original editor's green/water colours and checker shading; these vector terrain symbols contain no extracted original bitmap assets.

The header wordmark and brush-S favicon are independently drawn SVG outlines inspired by the pale-yellow brush lettering on the original Stunts DOS cover (reference: https://upload.wikimedia.org/wikipedia/en/7/7c/Stunts-dos-cover.jpg). The cover image itself is not bundled. Stunts remains the original game's name; the HD / TRACK EDITOR caption identifies this standalone editor.

## Original DEFAULT track layout

The original `DEFAULT.TRK` layout from the supplied Stunts / 4D Sports Driving installation is embedded in `src/default-track.js` and the standalone webpage. The web package also includes `DEFAULT.TRK` for export/import interoperability. It contains 1,802 track-format bytes only: track identifiers, terrain identifiers, horizon and metadata. It includes no executable, bitmap, 3D model, car or audio resource.

DEFAULT is original game track data, not an editor-authored track. Its original ownership is retained; the editor's GPL license does not claim ownership of that track data. DEMO.TRK remains the example track authored for this editor.

## Original track-selection graphics and PlayStunts native renderer

The optional Game view uses the native software track-overview renderer from PlayStunts commit `b5180b0a54193974c3b398ec38e6680db99f67cf`. Its TypeScript sources and transitive dependencies are included unchanged in `vendor/playstunts/`; the two-function entry point and optional esbuild regeneration script are provided. The compiled JavaScript is `src/native-overview.js`. Renderer code remains GPL-3.0-only, covered by the included LICENSE.

`vendor/overview-resources.json.gz` contains the supplied original scene-resource template, overview ground models, five panorama raster banks, and VGA palette. `scripts/build.mjs` embeds a gzip/base64 version in `src/overview-resources.js` and the offline HTML. These are original Stunts / 4D Sports Driving graphics and data, not newly authored graphics; original ownership is retained. The GPL license on editor/renderer code does not relicense or claim ownership of these original game resources.

The scene template is generated by PlayStunts `tools/generate_startup.ts` from initialized original data tables and expanded GAME1/GAME2 scene shape banks. It is not a captured user session and contains no DOS executable. Ground models come from GAME2.P3S. The panorama banks are converted DESERT.PVS, TROPICAL.PVS, ALPINE.PVS, CITY.PVS and COUNTRY.PVS resources, using the supplied original palette. No driving executable or audio is needed or included.

SHA-256 of the source 1 MiB scene template: `835adc6d47511946b21d9e9bfb0c758a889adde221c8fd2b211d604f4aa3c7aa`. The panorama resource records retain their original source filenames and SHA-256 hashes in the source JSON. The editable top-down map and palette still use independently authored SVG illustrations.

## Native track validation (version 1.6.0)

`src/native-route-validation.js` bundles the unchanged terrain and route-analysis code from the pinned PlayStunts revision recorded in `vendor/native-validation-provenance.json`. All transitive TypeScript sources and route descriptors are preserved in `vendor/playstunts/`; the entry point is `scripts/native-validation-entry.ts`. Code remains GPL-3.0-only. Original route descriptors retain their original ownership. Normal builds use the vendored JavaScript and need no network or npm dependencies. Optional regeneration uses esbuild through `scripts/build-native-validation.mjs`.
